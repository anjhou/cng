Anti-cavitation orifice design calculation procedure

Procedure for Estimating the Orifice Cavitation Limit Coefficient

The cavitation index is defined by:

σ = ΔP / (Pv − Ps)

where ΔP is the macroscopic pressure drop across the orifice,
Pv is the vapor pressure of the liquid,
Ps is the pressure downstream of the orifice.

The cavitation resistance factor β is a correction applied to the cavitation index for orifices or plates with similar cavitation behavior. β has a finite lower limit of 1.

When the operating cavitation index equals the critical cavitation index:

σ = σc

then:

β = σc / σ = 1

For β < 1, the operating cavitation index σ is less than the critical cavitation limit σc.
For β > 1, the operating cavitation index σ is greater than the cavitation limit index σc.

Calculation Procedure

  1. Calculate the dynamic pressure ratio (velocity head):
    Pv = (1/2) ρ V²
  2. Calculate the non-dimensional dynamic head:
    σ = ΔP / Pv
    The product of this value and the orifice plate value is the operating cavitation index.
  3. Calculate the maximum orifice limit:
    Km = ΔPm / Pv
    where ΔPm is the user-specified maximum pressure drop per plate.
  4. Assume a critical cavitation limit σc.
    The assumed value may be between 0 and 0.801.
  5. Calculate the operating cavitation index based on σc and β:
    σ = σc / β = σc / (1 − (1 − σc)(1 − β))

    For σ < σc:
    β = 2.13109 σc1.15472 σc − 1.0376 σc + 1.0055
  6. Calculate the orifice loss coefficient:
    Ko = 2.8 β⁻¹ + (1 − β)
  7. Calculate the orifice resistance coefficient:
    Kr = σ Ko
  8. Calculate the error:
    Error = Kr − Km

    If |Error| < 0.001, the increment may be accepted.
    If |Error| > 0.001, adjust the tolerance and repeat.
    If Error < Tolerance → acceptable.
    If Error > Tolerance → unacceptable.
  9. Return to Step 4 or Exit.
